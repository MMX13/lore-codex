# Lore Codex

A small, personal wiki for keeping track of names, places and lore while playing — built as a phone web app and hosted on GitHub Pages.

- **Your notes never leave your phone.** Everything is stored in the browser on your device. Nothing is synced or uploaded.
- **Starts empty.** No lore is pre-loaded, so no spoilers — only what you write.

## Using it

- **Install it:** open the site on your phone, then *Share → Add to Home Screen* (iPhone) or *⋮ → Install app* (Android). Installing also protects your notes from being cleared by the browser.
- **＋** creates a page: title, type, tags, "also known as" names, and free-form notes.
- **Hold anywhere on a page** to start writing at that spot. Tap **Done** when finished (it saves as you type).
- **Link pages** by typing `@` and picking a name, or tap the "Link to …?" chip that appears when you type an existing page's name.
- **Tap an "also known as" name** to make it the main title. Links keep working.
- **Archive** a page from its ⋯ menu. Links to it turn faded; tap one to restore it or start a new page.
- **Settings (⚙)**: edit page types, open the archive, and save/restore a backup file. Make backups now and then.

## Hosting

Plain static files — no build step. In the repo's *Settings → Pages*, set *Source* to *Deploy from a branch*, branch `main`, folder `/ (root)`.
